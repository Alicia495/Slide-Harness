# 監査指摘の修正計画

## 目的

全体監査で確認したセキュリティ、AI 編集、競合制御、出力整合性、UI/UX の不具合を、既存の公開動作と未コミット変更を保ちながら修正する。

## 実装順序

1. モデル探索時の保存済み API キー流出と SSRF を防ぎ、脆弱な本番依存を更新する。
2. AI 小修正、環境変数モデル、thinking 設定、出力トークン、コンテキスト切り詰めの整合性を修正する。
3. アセット参照検証、競合後の再同期、誤削除、保存再試行を修正する。
4. Dialog、狭幅 Drawer、短画面、保存状態、コントラスト、変更確認 UI を改善する。
5. render/export/asset の後始末、KPI ページ番号、角丸 PPTX 出力を修正する。
6. 単体テスト、型検査、本番ビルド、依存監査、実ブラウザ検証を行う。

## 互換性

- API の正常系レスポンス形式は維持する。
- 不正なモデル探索 URL と存在しないアセット参照は新たに拒否する。
- DB スキーマ変更は行わない。
- 認証なしの社内 LAN 利用という現行境界は維持する。

## 検証

- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- `pnpm audit --prod`
- デスクトップ、狭幅、短画面での実ブラウザ操作
